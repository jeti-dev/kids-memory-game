# Kids Memory Game

A memory matching game for kids (1+ years old), built with React, TypeScript, and Vite. Pick a topic (animals or clothing) and a card count (6-12), then flip cards to find the matching pairs. Fully client-side — no backend, no database.

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploying to GitHub Pages

This repo includes `.github/workflows/deploy.yml`, which builds the site and deploys it to GitHub Pages on every push to `main`.

One-time setup after creating the GitHub repo and pushing this code:

1. Push this repo to GitHub (e.g. `git remote add origin <url>` then `git push -u origin main`).
2. In the repo, go to **Settings → Pages** and set **Source** to **GitHub Actions**.
3. The next push to `main` (or a manual run of the workflow from the **Actions** tab) will publish the site to `https://<user>.github.io/<repo>/`.
